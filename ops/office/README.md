# PZ-Med Office

Закрытый внутренний реестр поставок PZ-Med на `https://pz-med.ru/office/`.

Хранит:
- заказчиков (государственные/частные);
- ИНН, договор и срок поддержки;
- первую установленную версию и дату;
- текущую версию;
- историю обновлений;
- Installation ID, build commit и SHA-256 поставки;
- необязательные служебные примечания и контакт ИТ.

## Безопасность

- серверная авторизация, пароль хранится только в виде хэша;
- CSRF-защита всех изменяющих запросов;
- ограничение неудачных попыток входа;
- Secure/HttpOnly/SameSite cookie;
- `noindex`, `no-store` и защитные HTTP-заголовки;
- база данных находится вне web-root: `/var/lib/pz-med-office/office.sqlite3`;
- секреты находятся вне Git: `/etc/pz-med-office.env`;
- сервис работает от отдельного непривилегированного пользователя `pz-med-office`.

## Первая установка

После обновления файлов сайта из GitHub:

```bash
sudo bash /var/www/pz-med.ru/ops/office/deploy_office.sh
```

При первой установке скрипт создаёт случайный пароль администратора и показывает его в терминале один раз. Логин по умолчанию: `admin`. После входа пароль следует заменить через раздел «Пароль».

Повторный запуск `deploy_office.sh` обновляет код, но сохраняет базу и действующий пароль.

## Резервное копирование

Основной файл данных:

```text
/var/lib/pz-med-office/office.sqlite3
```

Для резервного копирования безопаснее использовать SQLite backup API либо остановить сервис на время копирования файла. CSV-выгрузка доступна из интерфейса, но не заменяет резервную копию базы.
